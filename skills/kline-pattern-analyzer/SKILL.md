# K 線型態判讀

使用者丟一張 K 線圖，你要自己完成判讀，並給出明確結論：
- 這是什麼型態
- 看漲還是看空
- 多空的分界價位在哪
- 什麼情況代表判斷失效

不要反問使用者「你覺得呢」，也不要只給提示。

## 先找到腳本位置

以下用 `$SKILL` 代表本 skill 的資料夾（SKILL.md 所在處）。
- Claude Code 載入 skill 時會告訴你它的資料夾路徑（Base directory），直接用那個路徑。
- 不確定路徑時執行：

```bash
SKILL=$(dirname "$(find /mnt ~/.claude -name annotate_chart.py -path '*kline-pattern-analyzer*' 2>/dev/null | head -1)")/..
```

腳本需要 `matplotlib`、`numpy`，中文字型已內建在 `assets/fonts`。import 失敗時：
- 先試 `python3 -m pip install matplotlib numpy`（Windows 用 `py -m pip install matplotlib numpy`）。
- 出現 `externally-managed-environment` 錯誤時，建立虛擬環境：`python3 -m venv ~/.kline-venv && ~/.kline-venv/bin/pip install matplotlib numpy`，之後都用 `~/.kline-venv/bin/python` 執行腳本。
- 以下指令寫 `python`；依系統可能要改成 `python3` 或 `py`。

輸出圖片存到 `/mnt/user-data/outputs/`；沒有這個資料夾就存到目前工作目錄。存好後把檔案提供給使用者。

## 判讀流程

### 步驟 1：讀圖的基本資訊

- **標的、週期、期間、價格刻度**：圖上看得到就寫出來；看不到就直說「圖上沒顯示」，不要猜。
- **K 棒顏色慣例**：
  - 台股與多數台灣看盤軟體是「紅漲綠跌」。
  - 美股、TradingView 預設與多數加密貨幣交易所是「綠漲紅跌」。
  - 用整段走勢的方向對照 K 棒顏色來推斷，並在回覆中寫明你採用的假設。空心／實心 K 棒也一樣要判斷。
- **圖片品質**：遇到圖太小、K 棒太少（少於約 30 根）、或裁掉價格刻度時，仍然要給結論，但信心降一級，並說明需要什麼樣的圖才能判斷得更準。

### 步驟 2：找出型態

1. **前段趨勢**：先判斷是上漲、下跌還是盤整。反轉型態的前提是前面有一段趨勢可以反轉。
2. **找波段高低點**：把明顯的轉折高點、低點找出來，看它們連起來的結構。
3. **逐條對照條件**：圖表型態看 `references/chart-patterns.md`，K 線組合看 `references/candlestick-patterns.md`。逐條比對「辨識條件」，寫出哪些符合、哪些不符合。
4. **判定狀態**：
   - **形成中**：結構已出現，但還沒收盤突破頸線或關鍵價。
   - **已確認**：已收盤突破，最好伴隨量能放大。
   - **失敗**：突破後又回到型態內。失敗本身就是反方向的訊號，例如失敗的頭肩底偏空。
5. **型態數量**：主要型態最多 1 個；另一種解讀也說得通時，可以加 1 個備選。
6. **沒有明確型態**：直接說「沒有明確型態」，改用步驟 3 的趨勢結構判斷方向。

### 步驟 3：判斷看漲或看空

**先定起點**

- **有型態**：起點是 references 裡該型態標示的方向（看漲或看空）。
- **沒有型態**：用趨勢結構判斷。
  - 高點、低點都在墊高 → 看漲
  - 高點、低點都在下移 → 看空
  - 高低點交錯 → 中性

**再用四個因素調整強弱**

| 因素 | 加強 | 減弱 |
|---|---|---|
| 型態狀態 | 已確認（收盤突破加上量增） | 形成中；或突破後又回到型態內 |
| 大趨勢 | 與判斷方向一致 | 逆著大趨勢，例如空頭裡出現的小型底部 |
| 量能 | 突破時明顯放量 | 價漲量縮，或圖上看不到量能 |
| 位置 | 剛突破，離目標價還遠 | 已接近或超過目標價 |

**結論只能從這七級選一個**

- 看漲（強）、看漲（中）、看漲（弱）
- 中性（等突破）
- 看空（弱）、看空（中）、看空（強）

**分級規則**

- 只有「已確認」，而且至少兩個加強因素時，才能給「強」。
- 形成中的型態最多給「中」，並寫明要突破或跌破哪個價位才算確認。
- 對稱三角形、箱型這類方向未定的型態，還沒突破時給「中性（等突破）」。
- 單根或少數幾根的 K 線組合，最多給「中」，因為一定要隔天確認。

**一定要附上多空分界**，用兩個具體價位：
- 「站上（或守住）X 看漲成立」
- 「跌破 Y 判斷失效，轉為看空」

看空的判斷則反過來寫。

### 步驟 4：產生兩張圖

**A. 在使用者的原圖上標註（優先）**

1. 找到圖檔：
   - claude.ai：上傳的檔案在 `/mnt/user-data/uploads/`。
   - Claude Code：用使用者提供的檔案路徑（例如把圖檔拖進終端機得到的路徑）。使用者只貼上圖片、沒有檔案路徑時，先請他給路徑；拿不到就照下面 C 的方式處理。
2. 取得圖片尺寸與明暗：`python $SKILL/scripts/annotate_chart.py --image <圖檔> --info`
3. 依你看到的原圖，估計關鍵點的**比例座標**：x、y 都是 0–1，原點在圖片左上角，y 往下增加。
   - 先估出 K 線繪圖區的邊界（例如 x 0.04–0.92、y 0.12–0.80），再在區內定位。
   - 高點、低點以 K 棒影線的末端為準。
   - 頸線、趨勢線取兩個觸點，往右延伸過突破點一小段。
4. 寫一份 `spec.json`，格式見 `annotate_chart.py` 檔頭。內容包括：
   - `title`：型態名稱加狀態，例如「頭肩底（已確認）」。
   - `bias` 填 `bull`、`bear` 或 `neutral`，`verdict` 填結論，例如「看漲（強）」，會顯示在右上角。
   - `polyline` 型態骨架、2–4 個關鍵點 `points`、頸線或趨勢線 `lines`。
   - 兩條多空分界線：`kind: "bull"` 標「站上 X 看漲成立」，`kind: "bear"` 標「跌破 Y 轉看空」。
   - 已確認的圖表型態，加上目標價箭頭 `arrows`（`kind: "target"`）。
   - `notes` 2–3 條，寫具體價位與依據。
5. 執行：

   ```bash
   python $SKILL/scripts/annotate_chart.py --image <圖檔> --spec spec.json -o /mnt/user-data/outputs/判讀_<型態>.png
   ```

6. 如果你能檢視輸出的圖，確認標註有對到正確的 K 棒；明顯偏移就修正座標再跑一次，最多一次。估不準時，可以先用 `--grid -o grid.png` 疊上 10% 格線輔助定位。

**B. 標準型態示意圖**（有型態時附上）

```bash
python $SKILL/scripts/draw_pattern.py <型態代碼> -o /mnt/user-data/outputs/示意_<型態代碼>.png --convention tw
```

- `--convention` 要和原圖一致：`tw` 是紅漲綠跌，`us` 是綠漲紅跌。
- 用 `--list` 可以列出所有型態代碼。
- 箱型（`rectangle`）或對稱三角形（`symmetrical_triangle`）向下跌破時，加上 `--down`，畫成跌破的版本。

**C. 找不到上傳檔案時**：只產生 B，並在文字中描述型態在原圖上的位置，例如「左肩在 3 月中、約 580 元」。

### 步驟 5：回覆格式

```
**判讀結果：頭肩底（已確認）**
**方向：看漲（中）**

- 圖表資訊：日 K、約 2025/11–2026/02；依走勢判斷為紅漲綠跌
- 判斷依據：
  1. 前段由 450 附近下跌，符合「下跌後出現」
  2. 三個低點中間最低（約 335），左右肩約 380、375，高度接近
  3. 1 月下旬收盤帶量站上頸線約 405，型態確認
- 多空分界：站穩 405（頸線）以上維持看漲；跌破 375（右肩低點）判斷失效、轉為看空
- 目標價：約 470（頭部到頸線約 70，從突破點往上加）
- 強弱理由：已確認且突破放量（加強），但價格已接近目標價（減弱），所以給「中」
- 風險提醒：離目標價越近，追高風險越大
```

附上兩張圖。最後一行固定寫：「以上為技術型態判讀，不構成投資建議。」

## 多張圖、多個週期

- 每張圖先分別判讀，再寫綜合結論。
- 大週期（週 K、日 K）決定主方向，小週期（60 分、15 分）只用來看短線位置。
- 兩個週期方向矛盾時，就照實寫，例如「中線看漲、短線看空（回檔中）」，或直接給「中性（等突破）」。

## 只問型態、沒附圖時

依 references 說明型態的辨識、確認、失效與目標價，並用 `draw_pattern.py` 產生示意圖。使用者要全部型態時，用：

```bash
python $SKILL/scripts/draw_pattern.py --sheet -o /mnt/user-data/outputs/型態一覽表.png
```

## 原則

- **每次都要有方向結論**：從七級裡選一個（看漲、看空、中性加上強弱），不要只描述型態就結束。
- **結論要附條件**：同時寫出多空分界與失效條件，讓使用者知道什麼情況代表判斷錯了。
- **只說圖上看得到的**：看不到成交量就說看不到，不要編造價位或量能。
- **不做投資決定**：不保證漲跌、不預測日期，也不建議買賣金額或槓桿。型態有機率失敗，進場前一定要先設停損。
- **截圖可能被裁切**：只看到局部時，提醒使用者看更長的期間，可能會改變結論。
